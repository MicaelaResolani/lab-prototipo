# Prototipo de Sistema de Laboratorio 🧪🩺

Modelado y desarrollo de un entorno de software diseñado para la simulación y gestión de flujos de trabajo bioquímicos, manejo de datos críticos e interfaces orientadas a la optimización técnica en entornos analíticos de salud.

¡Podés probar la aplicación web armada con su interfaz visual funcionando en tiempo real acá!:
👉 **[Ver Aplicación en Vivo](https://micaelaresolani.github.io/lab-prototipo/)**

---

## 🛠️ Tecnologías y Metodologías Aplicadas
* **JavaScript (ES6+)** - Gestión de estados lógicos para el procesamiento de datos clínicos.
* **HTML5 & CSS3** - Maquetación avanzada y diseño de interfaces limpias para entornos médicos.
* **Arquitectura Modular** - Estructuración limpia del software pensada para la escalabilidad y facilidad de mantenimiento.
* **Control de Versiones** - Gestión avanzada del flujo de desarrollo mediante Git y GitHub.

## 📈 Características Destacadas del Proyecto
* **Simulación de Flujos Clínicos:** Optimización del recorrido de datos desde el ingreso de la muestra hasta la disponibilidad del informe técnico.
* **Interfaz Orientada al Usuario:** Diseño visual limpio enfocado en reducir la carga cognitiva en entornos analíticos y de alta presión.
* **Manejo Eficiente de Datos:** Estructura modular para simular el control de registros biológicos/clínicos con precisión.
